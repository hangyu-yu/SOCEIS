# SOCEIS → moved to EISAP

> **This repository has been renamed and moved.**
>
> **SOCEIS** (*Suite for Operando Characterisation of Electrochemical Impedance Spectra*) is now developed and maintained as **EISAP** (*Electrochemical Impedance Spectroscopy Analysis Program*).

## 👉 Go to the current repository: [github.com/hangyu-yu/EISAP](https://github.com/hangyu-yu/EISAP)

All development, releases, issues, and documentation now live there. This repository is kept only as a redirect for links and search results indexed under the old name.

---

## Install

The software is published on PyPI as [`eisap`](https://pypi.org/project/eisap/):

```bash
pip install eisap
```

The legacy `soceis` command remains available as a compatibility alias.

---

## Why the rename?

The project was originally released as **SOCEIS** and is now named **EISAP**. The PyPI package and primary CLI command use `eisap`; `soceis` remains available as a compatibility command and internal package identifier.

For full documentation, installation options, tutorials, and citation info, see the **[EISAP repository](https://github.com/hangyu-yu/EISAP)**.
